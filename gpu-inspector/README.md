# GPU Inspector & Profiler Add-on

First-party profiler dock for Teardrop Engine.

### Features
- Displays active rendering backend (WebGPU or WebGL2).
- Distinguishes CPU graph build time from CPU GPU-submission time.
- Queries GPU pass durations via asynchronous multi-frame WebGPU timestamp queries.
- Inspects format-based VRAM consumption across textures, render targets, and compute buffers.
